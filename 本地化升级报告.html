1已完成的 3D 地图功能

map.html 已从 2D SVG 示意图升级为本地化 3D 校园地图，基于 libs/three/three.min.js（Three.js v0.128 本地文件，无 CDN）。

1.1 场景内容（低面数建模，手机流畅）

  • 建筑：教学楼、6 个宿舍苑区、食堂、图书馆、体育馆/运动场、信息楼等，全部使用 Box/Cylinder 基础几何体，带高度层次、真实投影阴影（DirectionalLight castShadow）
  • 道路：按校园实际布局的路网，浅灰色路面 + 中心虚线
  • 绿化：草地色块 + 树木（InstancedMesh 批量渲染，降低 Draw Call）+ 路灯
  • 氛围：半球光 + 平行光 + 场景雾（fog），增强透视纵深感

1.2 视角与交互

  • 默认 45° 俯视透视相机（PerspectiveCamera）
  • 支持单指/鼠标拖动旋转（左右 theta）、上下俯仰（phi 有角度限制）、双指捏合/滚轮缩放（radius 有最近/最远限制），不会转到地图无法使用的角度
  • 工具条：放大 / 缩小 / 重置视角 / 回到定位

1.3 用户定位

  • 调用 navigator.geolocation.getCurrentPosition()，成功后按 WGS84 → 涵江校区经纬度投影校准落到 3D 场景，显示蓝色定位点 + 脉冲光圈 + “我的位置”标签
  • 失败/拒绝授权时降级为本地默认位置（图书馆北侧），功能不中断

1.4 3D POI 与路线

  • 6 个取件点（菜鸟驿站楷苑/南门、兰苑/菊苑快递柜、京东、顺丰）渲染为可点击 3D 立体标记（Raycaster 点击拾取，呼吸动画）
  • 点击后底部弹出信息卡：名称 / 类型（驿站·快递柜）/ 营业状态与时间 / 待取快递数量（实时计算） / 路线距离与步行时间 / “前往这里”
  • 本地路径规划：路网节点+边保存在页面内 CAMPUS_DATA（nodes/edges JSON），Dijkstra 最短路计算“用户 → 路网 → 取件点”，渲染发光虚线路线 + 流光脉冲，并显示“距离：120m / 预计步行：2分钟”

1.5 配送模式（外卖联动）

  • URL 参数 map.html?mode=delivery&orderId=xxx 进入
  • 显示店铺 POI、收货地址标记、3D 电动车骑手模型（含保温箱）沿路线移动
  • 顶部配送状态条：配送中徽章 / 预计送达 X 分钟（倒计时） / 配送距离 XXXm / 订单号 / 实时进度条；底部配送卡片：店铺 → 收货地址、商品件数、合计金额
  • 订单完成后地图显示“已送达”

验收通过浏览器实测：3D 场景渲染正常，无 Three.js/WebGL 报错。

2已完成的 OCR 扫码功能（scan.html）

2.1 识别流程

打开 scan.html→ 请求摄像头权限 getUserMedia→ 实时取帧：先识别二维码（jsQR）→ 无二维码则启动 OCR（Tesseract.js）→ 正则提取取件码→ 匹配本地快递库→ 发现快递 → 确认取件

2.2 摄像头

  • 真实摄像头取流（facingMode: environment 后置优先），视频帧送入本地识别引擎
  • HTTPS 环境下生效；失败时降级为手动输入取件码，不阻断使用

2.3 二维码 + OCR 双引擎

  • 二维码：libs/qr-scanner/jsQR.js 逐帧识别，支持 JSON 格式（含 packageId）与纯文本取件码
  • OCR：libs/tesseract/（Tesseract.js 本地版）只识别扫描框区域（截图 → 灰度 → 二值化增强 → 识别），白名单限制为数字/字母/连字符/冒号，不整图识别，速度更快、误识更少
  • 相册导入图片同样走“二维码 → OCR”两级兜底

2.4 取件码提取规则（api.js）

  • 自动清理空格、换行、全角冒号等噪声字符
  • 三层正则提取：① 三段式（8-3-267 / A-12-568 / 12-35-88 / C-12-45 纯字母首段）② 中文前缀（“取件码：8-3-267”、“取件码 83267”、“取货码/提取码/凭码”）③ 4–8 位纯数字兜底（83267）
  • 候选逐个归一化匹配本地快递数据库（pickupCode 无视大小写与分隔符）
  • 匹配成功 → 弹出“发现快递”卡片（快递公司 / 单号 / 取件码 / 取件点）；无匹配 → “未找到对应快递，请重新扫描或手动输入取件码”

2.5 识别 UI

  • 扫描框提示“将取件码对准扫描框”+ 扫描线往返动画
  • 识别成功：扫描框变绿并放大（scan-frame--success 动画）
  • 确认取件后状态 pending → picked 写入 localStorage，并联动取件记录、消息通知、累计取件数

验收通过浏览器实测：手动输入 8-3-267 成功匹配 SF 包裹并完成取件；node 端 11 项 OCR 提取规则全部通过（含字母段、中文前缀、噪声文本）。

6浏览器权限要求

功能权限不授权的后果
扫码取件（摄像头）摄像头 + 必须 HTTPS（或 localhost）降级为手动输入取件码，功能不中断
OCR 面单识别同摄像头；首次识别需加载本地 wasm（约 4.7MB，仅一次）可改用相册导入图片识别
3D 地图定位地理位置（geolocation）使用本地默认位置（图书馆北侧）
取件提醒通知浏览器 Notification（可选）仅站内消息中心提示
数据持久化localStorage隐私模式自动降级为内存存储（仅当次会话有效）
手机访问自签名 HTTPS 站点：首次会提示“不安全的证书”，点击高级 → 继续访问即可；摄像头必须在此 HTTPS 环境下才可用。

7本地启动方式

# 进入项目根目录
cd campus-package-app

# 启动本地 HTTPS 服务（node-forge 自动生成证书，端口 3000）
node server.js

# 访问（首次需信任自签名证书）
本机：    https://localhost:3000/login.html
局域网：  https://192.168.x.x:3000/login.html
远程组网：https://100.x.x.x:3000/login.html  # Tailscale 内网地址（示例已脱敏）

# 运行自动化验收（100 项，无需浏览器）
node verify.js

登录方式：手机号 + 验证码，验证码打印在启动服务的终端（开发模式）。file:// 直开 HTML 会导致 API/摄像头失败，务必经 server.js 访问。
